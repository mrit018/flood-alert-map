# flood-alert-map

แผนที่แจ้งเตือนน้ำท่วมบนถนน **เขตจังหวัดกาญจนบุรี** — รายงานจุดน้ำท่วม ส่งรูปและข้อความอัปเดตต่อได้ตลอด พร้อมระบบแจ้งเตือน

ไฟล์เดียวจบ เปิดใช้งานได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้อง build

🌐 **เว็บออนไลน์:** <https://mrit018.github.io/flood-alert-map/>

## เปิดใช้งานแบบออนไลน์ (GitHub Pages)

push เข้า `main` แล้วเว็บจะอัปเดตอัตโนมัติ ใช้เวลาไม่กี่นาที

เปิดใช้งานครั้งแรก (ทำครั้งเดียว) — ต้องล็อกอินเป็นเจ้าของ repo:

1. ไปที่ https://github.com/mrit018/flood-alert-map/settings/pages
2. หัวข้อ **Build and deployment** → **Source** เลือก **GitHub Actions**
3. กด Save

workflow จะ deploy อัตโนมัติทุกครั้งที่ push

## เปิดใช้งานแบบในเครื่อง

```bash
open index.html
```

หรือเสิร์ฟผ่าน HTTP (แนะนำ — Geolocation บางเบราว์เซอร์จะปฏิเสธบน `file://` และ Google Maps ต้องการ origin จริง):

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/
```

> `python3 -m http.server` จะเสิร์ฟทั้งโฟลเดอร์รวมถึง `.git/` — เห็นไฟล์ประวัติ git ได้ ถ้าอยากจำกัดขอบเขตให้ดูหัวข้อ "เสิร์ฟแบบปลอดภัย" ท้ายไฟล์

`flood-alert-map.html` เป็นไฟล์ redirect ไปที่ `index.html` — คงไว้เพื่อให้ลิงก์เก่ายังใช้ได้

## เขตพื้นที่

ระบบจำกัดอยู่**เฉพาะจังหวัดกาญจนบุรี**

```
เหนือ 15.6607  ·  ใต้ 13.7261  ·  ตะวันออก 99.8793  ·  ตะวันตก 98.1817
```

- แผนที่ล็อกไว้ในกรอบนี้ เลื่อนหรือซูมออกไปไม่ได้
- คลิกเพื่อรายงานนอกเขต → ระบบปฏิเสธ
- รายงานที่นำเข้ามาและอยู่นอกเขต → ถูกกรองทิ้งอัตโนมัติ
- ถ้าตำแหน่งปัจจุบันของคุณอยู่นอกเขต ระบบจะบอกว่าเปิด "แจ้งเตือนใกล้ฉัน" ไม่ได้

## แผนที่: Google Maps หรือ OpenStreetMap

ระบบเลือกอัตโนมัติ:

| สถานะ | ได้แผนที่อะไร |
|---|---|
| ใส่ Google Maps API key | **Google Maps** พร้อม Street View |
| ยังไม่ใส่ key | **OpenStreetMap** (ทำงานได้ครบ ไม่ต้องมี key) |
| ใส่ key แล้วแต่เปิดไม่สำเร็จ | ลอง OpenStreetMap พร้อมข้อความบอกสาเหตุ |

### วิธีใส่ Google Maps API key

1. ไปที่ [console.cloud.google.com](https://console.cloud.google.com) → สร้าง project
2. เปิดใช้ **Maps JavaScript API**
3. ผูก **Billing account** (มีเครดิตฟรี $200/เดือน — ขาดแล้วแผนที่จะไม่โหลด)
4. สร้าง API key แล้ว**จำกัด referrer** ไว้ที่โดเมนที่จะใช้จริง
5. กด ⚙ (เฟือง) มุมขวาบนของแอป → วาง key ในช่อง "Google Maps API key" → บันทึก

key ถูกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น **ไม่ได้ฝังในไฟล์** และไม่หลุดไปกับการส่งออก/นำเข้าข้อมูล

> ถ้าไม่อยากสมัคร Billing ให้ใช้ OpenStreetMap ไปก่อน ไม่มีอะไรขาด

### ⚠️ อย่าฝัง key ลงในไฟล์ HTML

เว็บบน GitHub Pages เปิดสาธารณะ **ถ้าฝัง key ลงใน `index.html` ใครก็ scrape ไปใช้ได้** แล้วโดนเรียกเกินโควตา — ค่าใช้จ่ายไปที่บัญชีของคุณ

แอปนี้อ่าน key จาก `localStorage` ของผู้ใช้แต่ละคน แปลว่า**เว็บที่ deploy ไปไม่มี key ฝังอยู่เลย** ทุกคนที่เปิดจะได้ OpenStreetMap ไปก่อน แล้วค่อยใส่ key ของตัวเองถ้าอยากได้ Google Maps

ถ้าจำเป็นต้องมี key กลางสำหรับทุกคน ให้ใช้ key ที่**จำกัด referrer** เป็นโดเมนของ Pages และ**จำกัดโควตา**ไว้ใน Google Cloud Console ทุกครั้ง

## ฟีเจอร์

**รายงานน้ำท่วม**
- แตะบนแผนที่เพื่อวางจุด หรือใช้ตำแหน่งปัจจุบันของคุณ
- ระดับน้ำ 3 ระดับ: เฝ้าระวัง (<30 ซม.) / ท่วมขัง (30–80 ซม.) / รุนแรง (>80 ซม.)
- ชื่อถนน ความลึกโดยประมาณ และรายละเอียดเพิ่มเติม
- แนบรูปได้สูงสุด 4 รูปต่อโพสต ย่อขนาดให้อัตโนมัติ (ไม่เกิน 1400px, JPEG คุณภาพ 0.72)

**ฟีดอัปเดตสด**
- ทุกคนโพสตรูปและข้อความต่อที่จุดเดิมได้ ไม่ต้องสร้างจุดใหม่
- แท็บ "ฟีดอัปเดต" รวมโพสตทั้งหมดเรียงตามเวลา
- แตะรูปเพื่อดูขนาดเต็ม เลื่อนซ้ายขวาได้ ปิดด้วย `Esc` หรือปุ่มลูกศร

**ผู้รายงาน**
- ตั้งชื่อและเบอร์โทรครั้งเดียวที่ปุ่มเฟือง ใช้ซ้ำได้ทุกโพสต
- เบอร์แสดงเป็นลิงก์ `tel:` กดโทรได้ทันที
- ซ่อนเบอร์ของตัวเองได้ ระบบจะเขียนกำกับว่าซ่อนไว้ให้คนอื่นส่งข้อความแทน
- ลบโพสตของตัวเองได้ (ระบบเทียบจากชื่อที่ตั้งไว้)

**การแจ้งเตือน**
- รัศมี 1–30 กม. ปรับได้ทีละขั้น
- เลือกขั้นต่ำที่จะแจ้ง: ทุกระดับ / ตั้งแต่ท่วมขังขึ้นไป / เฉพาะรุนแรง
- กดดาวที่จุดเพื่อ **ติดตาม** จุดนั้น — จะเตือนทุกครั้งที่มีโพสตใหม่ ไม่ว่าจะอยู่ไกลแค่ไหน
- แจ้งเตือนได้ทั้งเบราว์เซอร์ (พร้อมรูปประกอบ) และในหน้าเว็บ พร้อมเสียง
- ถ้าเบราว์เซอร์บล็อกการแจ้งเตือน ปุ่มจะขึ้นว่า "ถูกบล็อก" — การแจ้งเตือนในหน้าเว็บยังทำงาน

**การจัดการข้อมูล**
- "น้ำลดแล้ว" ย้ายจุดไปหมวด "น้ำลดแล้ว" แทนการลบทิ้ง ประวัติโพสตยังอยู่
- ส่งออก/นำเข้าเป็น JSON พร้อมรูปในตัวไฟล์
- นำเข้าจุดที่มี id ซ้ำจะ **รวมโพสต** เข้าไป ไม่ทับข้อมูลเดิม
- ซิงก์ข้ามแท็บอัตโนมัติ (รวมโพสตของทั้งสองฝั่ง ไม่ให้หายไปข้าง)

## ข้อจำกัดที่ควรรู้

ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน ไม่มีเซิร์ฟเวอร์:

| หัวข้อ | รายละเอียด |
|---|---|
| การมองเห็นร่วมกัน | ไม่มี — แต่ละเครื่องเห็นแค่ข้อมูลตัวเอง ยกเว้นซิงก์ข้ามแท็บในเบราว์เซอร์เดียวกัน |
| ค่าใช้จ่าย Google Maps | มีเครดิตฟรี $200/เดือน แต่ถ้าใช้เกินต้องผูกบัตร (ใช้ OpenStreetMap ไม่มีค่าใช้จ่าย) |
| การส่งออก/นำเข้า | ต้องทำเองทีละเครื่อง เป็นวิธีเดียวที่จะย้ายข้อมูลข้ามเครื่อง |
| พื้นที่รูป | จำกัดด้วยโควตาของเบราว์เซอร์ (ราย 100–300 KB หลังย่อ) |
| การแจ้งเตือนข้ามเครื่อง | ไม่ได้ — ต้องมี push server ถ้าต้องการ |
| การยืนยันตัวตน | ไม่มี — ใครก็โพสตได้ โดยชื่อที่ตั้งเอง |
| พื้นที่ | จำกัดเขตกาญจนบุรี รายงานนอกเขตจะถูกปฏิเสธ |
| การลบโพสต | เทียบจากชื่อที่ตั้งไว้ ถ้าเปลี่ยนชื่อทีหลังจะลบโพสตเก่าของตัวเองไม่ได้ |

ถ้าต้องการให้หลายคนเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ ต้องเชื่อมต่อฐานข้อมูลหรือเซิร์ฟเวอร์ (เช่น Firebase, Supabase) — ส่วนรูปควรเก็บบน object storage แยก แล้วเก็บแค่ URL ในฐานข้อมูล

## เทคโนโลยี

- ไฟล์ HTML ไฟล์เดียว ~114 KB ไม่มี build step ไม่มี dependency ตอนรัน
- **Google Maps JavaScript API** (โหลดตอนใช้งานเมื่อมี key) หรือ **Leaflet 1.9.4 + OpenStreetMap** (สำรอง)
- `localStorage` เก็บข้อความ (รายงาน โพสต ตั้งค่า โปรไฟล์ API key)
- `IndexedDB` เก็บรูป (localStorage จำกัด ~5 MB เก็บรูปไม่ได้)
- Notification API + Geolocation API
- รองรับโหมดมืด (`prefers-color-scheme`) และจอเล็ก

ชั้นแผนที่ถูกแยกเป็น adapter เดียวกันสอง backend (`makeGoogleMap` / `makeOsmMap`) ที่เปิดหน้าการใช้งานชุดเดียวกัน จึงสลับ backend ได้โดยไม่ต้องแตะโค้ดส่วนอื่น

## โครงสร้างข้อมูล

ข้อมูลใน `localStorage` คีย์ `floodwatch.v2`:

```jsonc
{
  "id": "r1a2b3c",              // ไม่ซ้ำในระบบ
  "lat": 13.7123, "lng": 100.5560,
  "level": 2,                   // 1 | 2 | 3
  "depth": 45,                  // ซม. หรือ null
  "place": "ถนนพระราม 4",       // ชื่อสถานที่/ถนน
  "note": "รถเล็กผ่านไม่ได้",    // คำอธิบายตอนรายงาน
  "ts": 1758000000000,
  "resolved": false,            // true = น้ำลดแล้ว
  // lat/lng ต้องอยู่ในเขตกาญจนบุรี ไม่งั้นจะถูกทิ้ง
  "posts": [                    // ไทม์ไลน์อัปเดต
    {
      "id": "p4d5e6",
      "text": "น้ำลดถึงทางเท้าแล้ว",
      "photos": ["p7x8y9"],      // อ้างอิงคีย์ใน IndexedDB
      "author": { "name": "สมชาย", "phone": "081-234-5678" },
      "ts": 1758000060000
    }
  ]
}
```

`photos` เก็บใน IndexedDB คีย์ `floodwatch-media` → object store `photos` → `{ id, blob, w, h, ts }`

คีย์อื่นใน localStorage:

- `floodwatch.settings.v1` — เปิด/ปิดแจ้งเตือน, เสียง, ขั้นต่ำ, รัศมี, รายการจุดที่ติดตาม, **Google Maps API key**, mapId
- `floodwatch.identity.v1` — ชื่อ, เบอร์โทร, ตัวเลือกซ่อนเบอร์

## ทดสอบ

รันสองชุดทดสอบด้วย jsdom + fake-indexeddb (ไม่ต้องเปิดเบราว์เซอร์):

```bash
npm install
npm test                 # รันทั้งสองชุด
node test-flood.js       # ฟีเจอร์หลัก 90 เคส
node test-regress.js     # บั๊ก 14 จุดที่เคยเจอ 39 เคส
```

เทสต์อ่านไฟล์ `index.html` โดยตรง จึงทดสอบได้โดยไม่ต้องเปิดเบราว์เซอร์

## เสิร์ฟแบบปลอดภัย (ไม่เปิด `.git/`)

`python3 -m http.server` เสิร์ฟทุกไฟล์ในโฟลเดอร์ รวม `.git/` ถ้าอยากจำกัดขอบเขต:

```bash
python3 -c "
import http.server, socketserver
class H(http.server.SimpleHTTPRequestHandler):
    def do_GET(self):
        if self.path.startswith('/.git') or self.path.startswith('/test-'):
            self.send_error(404); return
        if self.path in ('/', '/index.html'):
            self.path = '/index.html'
        return super().do_GET()
socketserver.TCPServer.allow_reuse_address = True
with socketserver.TCPServer(('', 8000), H) as s: s.serve_forever()
"
```

## สิ่งที่ควรระวังเรื่องความเป็นส่วนตัว

ระบบนี้เก็บเบอร์โทรและรูปชนะทะเละไว้ในเครื่องผู้ใช้ และระบบแจ้งเตือนจะพยายามรักษาความเป็นส่วนตัว แต่การส่งต่อข้อมูลระหว่างเครื่องผ่านไฟล์ JSON ที่ส่งออกยังทำให้ความเป็นส่วนตัวหลุดได้ — ควรส่งผ่านช่องทางที่เข้ารหัสหรือส่งตรงกับผู้รับเท่านั้น อย่าลงบนพื้นที่สาธารณะ
